## 📌 Overview
Welcome to the Cloud Computing Security Essentials repository. This project is dedicated to mastering foundational and advanced cloud computing concepts with a strong emphasis on cybersecurity. 

It serves as a comprehensive portfolio containing lab reports, practical implementation guides, and technical documentation generated throughout the course. The primary goal is to demonstrate a hands-on understanding of identity governance, least privilege, cloud orchestration, and container security.

## 🎓 Course Information
- **Course Code:** IKB42603
- **Focus Area:** Cloud Computing Security Essentials
- **Objectives:**
  - Understand core cloud architecture and security principles.
  - Implement Identity and Access Management (IAM) best practices.
  - Explore Role-Based Access Control (RBAC) in Kubernetes environments.
  - Safely emulate and audit cloud infrastructure using local simulators.

## 📁 Repository Structure
- **/Lab 0:** Environment Setup Report (Docker, AWS CLI v2, LocalStack, Kubernetes/kind).
- **/Lab 1:** Account Security and IAM (Implementing least privilege, fine-grained permissions, and Kubernetes RBAC).
- **/Quiz:** Course quizzes and theoretical assessments.

## 🛠️ Technologies Used
- **Cloud Simulation:** [LocalStack](https://localstack.cloud/)
- **Containerization & Orchestration:** [Docker](https://www.docker.com/), [Kubernetes (kind)](https://kind.sigs.k8s.io/)
- **CLI Tools:** AWS CLI v2, `kubectl`
- **Security & Access Control:** AWS IAM, Kubernetes RBAC
